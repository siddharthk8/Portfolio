# Portfolio

This is a personal portfolio website designed to present projects, skills, experience, and contact information in a clean, modern interface.

## About

The site is built as a single-page frontend with reusable sections for the hero area, about content, experience, skills, projects, and contact details. It focuses on a polished visual presentation with motion and interactive UI elements.

## Tech Stack

- React
- Vite
- React Router
- Framer Motion
- Tailwind CSS
- Recharts
- Lucide React

## Highlights

- Modular component structure
- Responsive layout
- Animated and interactive sections
- Clean, modern portfolio presentation
